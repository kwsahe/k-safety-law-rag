> 사고 유형: 끼임·협착 (프레스 기계 방호장치 미설치)
> 사업장 규모: 상시 근로자 28명 (두 법령 모두 적용)
> 핵심 검증: 기계 방호장치 조항 (제87조·별표5 제1호) — 이전 사고와 다른 조항 체계
> 난이도 구성: 1단계(위반 조항) · 2단계(책임 주체) · 3단계(종합 평가) 균형

```
[사고 개요]
- 현장: 자동차 부품 제조 공장 프레스 작업 구역

- 사고 일시: 2024년 6월 10일, 오후 3시경
- 사고 위치: 공장 1층 프레스 작업장 (200톤 동력 프레스)
- 사고 결과: 프레스 금형 작동 중 작업자 T씨의 오른손이

사고 당시 페달식 조작만 가능한 상태로 작업이 진행되고 있었으며,

- 특별안전교육: T씨 프레스 작업 관련 미실시
- 작업 전 위험성평가: 미실시
- 방호장치: 광전자식 방호장치 고장 방치, 양수조작식 미작동
- 자율안전확인신고: 프레스 안전검사 미실시
- 안전보건관리체계: 형식적으로 마련되어 있으나

- 보호구: 안전장갑 착용 (금형 협착과는 무관)
- 도급 관계: 없음 (직영 작업)
- 작업지휘자: 미배치
```

## Q1. 난이도: 하 — 프레스 작업 특별안전교육 위반

**프롬프트:**
```
위 사고에서 프레스 작업 관련 특별안전교육 미실시가
법령 위반에 해당하는가?
위반 조항과 교육 내용을 함께 제시하라.
```

**정답:**
```
위반 여부: YES

[위반 조항]
산업안전보건법 시행규칙 별표 5 제1호, p.79
- 대상: 프레스·전단기를 사용하는 작업
- 근거: T씨가 200톤 동력 프레스 작업 수행
        프레스 작업 특별교육 미이수 → 위반 성립

[교육 내용]
① 프레스의 특성과 위험성에 관한 사항
② 방호장치 종류와 취급에 관한 사항
③ 안전작업방법에 관한 사항
④ 프레스 안전기준에 관한 사항
⑤ 그 밖에 안전·보건관리에 필요한 사항

근거: 산업안전보건법 시행규칙 [별표 5] 제1호, p.79
```

**평가 기준:**
| 항목 | 배점 |

| 프레스 작업 단서 → 해당 조항 적용 명시 | 25점 |

**실패 패턴:**

- 교육 내용에 타 작업 항목 혼입

## Q2. 난이도: 중 — 방호장치·안전검사 위반

**프롬프트:**
```
위 사고에서 확인된 프레스 방호장치 미작동,
안전검사 미실시, 정비 시 조치 위반이
법령 위반에 해당하는가?
각 항목별로 위반 조항과 함께 판단하라.
```

**정답:**
```
[위반 사항 3가지]

① 프레스 방호장치 미설치·미작동
   - 근거: 산업안전보건기준에 관한 규칙 제103조
   - 판단: 프레스 작업 시 슬라이드 하강으로 인한
           협착 방지를 위해 방호장치(광전자식·양수조작식 등)
           설치·유지 의무 → 고장 방치 위반

② 프레스 안전검사 미실시
   - 근거: 산업안전보건법 제93조
   - 판단: 프레스는 안전검사 대상 유해·위험기계
           정기 안전검사 미실시 → 위반

③ 정비·수리 시 운전 정지 및 조치 미실시
   - 근거: 산업안전보건기준에 관한 규칙 제92조
   - 판단: 금형에 걸린 소재 제거 시 전원 차단 등
           운전 정지 후 작업 의무 → 전원 미차단 위반
           (기동장치 잠금 또는 표지 부착 의무 포함)
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 방호장치 + 제103조 | 35점 |
| 안전검사 + 제93조 | 30점 |
| 정비 시 운전정지 + 제92조 | 35점 |

**실패 패턴:**
- 특별교육(별표5 제1호)만 반복 (Q1 답변 재출력)
- 방호장치 조항 미검색
- 제103조·제93조·제92조가 임베딩 안 된 경우

## Q3. 난이도: 상 — 중대재해처벌법 적용 + 처벌 수위 (부상 1명 함정)

**프롬프트:**
```
위 사고에서 중대재해처벌법이 적용되는가?
(주)대한정밀프레스 대표이사의 의무 위반 여부와
처벌 수위를 판단하라.
부상자가 1명인 경우 적용 요건을 명확히 검토하라.
```

**정답:**
```
[중대재해처벌법 적용 여부]
적용 안 됨 (또는 신중 검토 필요) — 핵심 함정

제2조제2호 중대산업재해 요건:
  가목: 사망자 1명 이상 → 이 사고 해당 없음 (사망 없음)
  나목: 동일 사고로 6개월 이상 치료 부상자 2명 이상
        → 이 사고는 부상자 1명 (T씨)
        → 나목 요건(2명 이상) 미충족
  다목: 직업성 질병자 1년 내 3명 이상 → 해당 없음

→ 부상자 1명(6개월 이상 치료)은
  중대재해처벌법상 중대산업재해 요건 미충족
→ 중대재해처벌법 미적용

[중요 구분]
- 6개월 이상 치료가 필요한 부상이라도 "1명"이면
  중대산업재해에 해당하지 않음 (2명 이상 필요)
- 사망이 아니므로 가목도 미해당

[산업안전보건법은 적용됨]
- 방호장치 미설치, 안전검사 미실시, 특별교육 미실시 등
  산업안전보건법 위반은 인원수와 무관하게 성립
- 처벌: 과태료 + 안전검사 미실시 등 행정처분·형사처벌

[대표이사 책임]
- 중대재해처벌법상 경영책임자 처벌은 이 사고에서 미적용
- 단, 산업안전보건법상 사업주 책임은 별도 성립
- 방호장치 방치는 산업안전보건법 제38조 안전조치 의무 위반

근거: 중대재해처벌법 제2조제2호 (요건 미충족)
     산업안전보건법 제38조, 제93조
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 부상자 1명 → 나목(2명) 미충족 판단 | 30점 |
| 사망 아님 → 가목 미해당 판단 | 20점 |
| 중대재해처벌법 미적용 결론 | 20점 |
| 산업안전보건법은 적용됨 구분 | 20점 |
| "6개월 이상이어도 1명이면 미해당" 명시 | 10점 |

**실패 패턴:**
- 6개월 이상 부상이라는 이유로 중대재해처벌법 적용 (오답)
- 부상자 1명인데 나목 적용 (2명 요건 무시)
- "중대재해처벌법 적용" 후 제6조제2항 처벌 수위 출력 (핵심 오답)

## Q4. 난이도: 최상 — 프레스 안전검사·자율안전확인 판단

**프롬프트:**
```
위 사고에서 프레스 기계 자체의 안전검사 및
자율안전확인 관련 사업주 의무 위반을 판단하라.
방호장치 관리 의무와 함께 관련 조항을 제시하라.
```

**정답:**
```
[프레스 안전검사 의무]
- 근거: 산업안전보건법 제93조
- 판단: 프레스는 안전검사 대상 기계
        (산업안전보건법 시행령 제78조)
        정기 안전검사(2년마다, 설치 후 3년 이내 최초)
        미실시 → 위반

[자율안전확인신고 의무]

        → 방호장치 고장 방치 후 페달식 작업은
          사실상 방호조치 무효화

[처벌]
- 안전검사 미실시: 산업안전보건법 제175조 과태료
- 방호조치 위반: 산업안전보건법 제38조 위반 →
  제168조 등 벌칙 (5년 이하 징역 또는 5천만원 이하 벌금)

근거: 산업안전보건법 제38조·제80조·제89조·제93조
```

## Q5. 난이도: 최상+ — 사고 상황 종합 평가

**프롬프트:**
```
위 사고 상황을 종합 평가하라.
다음 항목을 모두 포함하여 최종 보고서 형식으로 작성하라.

① 사고 원인 분석 (직접 원인 / 간접 원인)
② 법령 위반 사항 요약 (산업안전보건법 / 중대재해처벌법 적용 여부)
③ 책임 주체별 판단 (사업주 / 경영책임자 / 근로자)
④ 즉시 취해야 할 재발방지 조치 (법적 근거 포함)
```

**정답:**
```
[사고 원인 분석]

직접 원인:
- 프레스 전원 미차단 상태에서 금형 사이 손 삽입
- 페달 오조작으로 슬라이드 하강 → 손 협착

간접 원인:
- 광전자식 방호장치 고장 방치 (제103조)
- 양수조작식 조작부 미작동
- 프레스 안전검사 미실시 (제93조)
- 프레스 작업 특별안전교육 미실시 (별표5 제1호)
- 정비 시 운전정지 절차 미준수 (제92조)
- 작업지휘자 미배치

[법령 위반 사항 요약]

산업안전보건법:
- 별표5 제1호: 프레스 작업 특별안전교육 미실시
- 제38조: 방호조치 등 안전조치 의무 위반
- 제80조: 방호장치 임의 해제·미작동 방치
- 제89조: 자율안전확인신고 대상 방호장치 관리
- 제93조: 프레스 안전검사 미실시
- 기준규칙 제92조: 정비 시 운전정지 미실시
- 기준규칙 제103조: 방호장치 유지·관리 위반

중대재해처벌법:
- 적용 안 됨
- 사유: 사망자 없음(가목 미해당),
        6개월 이상 치료 부상자 1명(나목 2명 요건 미충족)
- 부상자가 1명이므로 중대산업재해 요건 미충족

[책임 주체별 판단]

사업주:
- 산안법상 방호장치·안전검사·교육 의무 위반 주체
- 과태료 + 방호조치 위반 형사처벌
  (제38조 위반 → 5년 이하 징역 또는 5천만원 이하 벌금)

경영책임자(대표이사):
- 중대재해처벌법 미적용 (부상자 1명)
- 단, 산안법상 사업주 지위 책임은 별도 성립 가능

근로자(T씨):
- 산안법상 처벌 주체 아님
- 전원 미차단 후 손 삽입은 근로자 과실 요소이나
  방호장치를 정상 관리하지 않은 사업주 책임이 선행
- 민사 과실상계는 법원 판단 영역

[재발방지 조치]

즉시:
1. 프레스 작업 중지 및 방호장치 수리·교체
   → 기준규칙 제103조
2. 광전자식·양수조작식 방호장치 정상 작동 복구
   → 산업안전보건법 제80조
3. 프레스 안전검사 즉시 실시
   → 산업안전보건법 제93조
4. 프레스 작업 특별안전교육 실시
   → 별표5 제1호, p.79
5. 정비·소재 제거 시 전원 차단 절차 수립
   → 기준규칙 제92조

사후:
6. 산업재해 발생 보고
   → 산업안전보건법 제57조, 별지 제30호서식
7. 전체 프레스 방호장치 정기 점검 체계 구축
8. 위험성평가 실시 및 작업표준 수립
```

## 이전 테스트셋과의 차이점 + 핵심 함정

| 항목 | 붕괴 사고 | 끼임 사고 |
|------|---------|---------|
| 핵심 조항 | 별표5 제19호 (굴착) | 별표5 제1호 (프레스) |
| 추가 위반 | 제338·339·340·347조 | 제92·103조, 제89·93조 |
| 사고 결과 | 부상 2명 | 부상 1명 |
| 중재법 적용 | 적용 (나목) | **미적용 (1명)** |
| 도급 관계 | D사 도급 | 직영 (도급 없음) |

**Q3 핵심 함정:**
```
붕괴 사고: 부상 2명 → 중재법 적용 (나목)
끼임 사고: 부상 1명 → 중재법 미적용

같은 "6개월 이상 치료 부상"이라도
인원(2명 vs 1명)에 따라 적용 여부가 갈림.
직전 붕괴 사고에서 "부상 2명 = 적용"을 학습한 뒤
이번에 "부상 1명 = 미적용"을 정확히 판단하는지 검증.
```
