# 정확도 평가 및 개선 기록

이 문서는 건설현장 중대재해-산업안전 법령 상담 챗봇의 답변 품질을
어떻게 평가했고, 초기 실패를 어떤 구조적 개선으로 해결했는지 기록한다.

프로젝트의 품질 지표는 다음 두 종류로 구분한다.

1. **수동 품질 평가 점수**: 법령 조항, 사실관계, 책임 주체와 답변 구성을
   사람이 문항별 루브릭으로 채점한 점수
2. **자동 배포 게이트 통과율**: 필수ㆍ금지 표현, 출처 정합성, 응답시간,
   시나리오 격리와 출력 계약을 코드로 검사한 회귀 테스트 결과

두 지표는 목적과 산정 방식이 다르다. 아래 결과는 프로젝트에 포함된
고정 평가셋의 성능이며, 모든 산업재해와 법률 질문에 대한 보편적인
법률 정확도를 의미하지 않는다.

## 평가 설계

### 문항 구성

각 사고 유형은 다음 다섯 관점으로 평가한다.

| 문항 | 검증 대상 |
|---|---|
| Q1 | 작업별 특별안전교육 대상과 정확한 별표 항목 |
| Q2 | 현장의 구체적 안전조치와 위반 조항 |
| Q3 | 사망ㆍ부상 인원에 따른 중대재해처벌법 적용과 처벌 |
| Q4 | 도급ㆍ직영ㆍ제조자 등 책임 주체와 질문 의도 분류 |
| Q5 | 사고 원인, 법령 위반, 책임과 재발방지를 포함한 종합보고서 |

### 수동 채점 기준

| 등급 | 점수 | 기준 |
|---|---:|---|
| S | 90~100 | 조항, 내용과 시나리오 맥락이 일치 |
| A | 80~89 | 핵심 조항은 정확하나 부가 내용 일부 누락 |
| B | 70~79 | 방향은 맞지만 일부 조항 오류 또는 누락 |
| C | 60~69 | 중요 항목이 누락되거나 절반가량 오류 |
| F | 60 미만 | 조항 오발화, 시나리오 혼입 또는 핵심 판단 오류 |

합격 기준은 문항별 70점 이상, 사고 유형 평균 80점 이상이다.

### 자동 게이트 기준

자동 평가는 단순 문자열 일치만 검사하지 않는다.

- 사고별 반드시 포함해야 하는 핵심 법령
- 다른 사고에서 가져오면 안 되는 회사명ㆍ작업ㆍ조항
- 사망자와 6개월 이상 치료 부상자 수에 따른 법 적용 분기
- 사업주, 경영책임자, 법인과 근로자의 책임 분리
- 답변에서 인용한 조항과 검색 근거의 일치
- page 7 법령 위반과 page 12 종합평가 payload 계약
- 질문 전체와 시나리오를 반영한 캐시 키 격리
- 60초 이내 응답
- 등록되지 않은 회사와 도급 구조를 사용한 holdout
- 일반 기업 법령 질문의 시나리오 비의존성

## 사고 유형별 개선

### 1. 용접ㆍ도장 화재·폭발: 43.6 → 98

**초기 실패**

- `철골 구조물`이 골조 라우팅을 작동시켜 별표 5 제27호가 출력됨
- 화기작업, 환기와 동시작업 관련 제241조ㆍ제232조ㆍ제240조가 누락됨
- 직접응답 경로에 과거 비계 사고의 회사와 작업 내용이 남아 있었음

**개선**

- `용접`, `화기`, `산소-아세틸렌`을 우선하는 작업 의도 분류 추가
- 골조 라우팅은 조립ㆍ해체 동작이 함께 있을 때만 작동하도록 축소
- 화재 관련 조항을 검색ㆍ직접응답 근거에 추가
- 직접응답이 현재 시나리오 프로파일의 회사ㆍ작업ㆍ도급 구조를 사용하도록 변경

**결과**

- 화기작업과 환기 조항이 종합보고서까지 일관되게 반영됨
- 다른 사고의 비계ㆍ굴착 조항과 회사명 혼입이 제거됨

원본: [`test/test_fire_explosion_result.md`](../test/test_fire_explosion_result.md)

### 2. 굴착 토사 붕괴: 33 → 99

**초기 실패**

- 별표 5 교육 내용과 페이지가 다른 행과 혼입됨
- 흙막이ㆍ굴착면 관련 조항이 검색되지 않음
- 장기치료 부상자 2명 사고를 사망 사고 처벌 구조와 혼동함
- 다른 시나리오의 답변이 도급 책임 경로에 남음

**개선**

- 별표 청크를 항목 단위로 재구성하고 페이지 매핑 수정
- 개정된 제338조ㆍ제339조ㆍ제340조ㆍ제347조 검색 근거 추가
- 사망자와 6개월 이상 치료 부상자를 별도로 계산하는 결정형 분기 적용
- 캐시 키에 질문 전체와 시나리오 식별 정보를 포함

**결과**

- 부상자 2명에 대한 제2조제2호나목, 제6조제2항 분기가 정확히 작동함
- 최신 조문 재배열까지 반영해 구버전 정답의 조항 번호를 교정함

원본: [`test/test_collapse_injury_result.md`](../test/test_collapse_injury_result.md)

### 3. 프레스 끼임·협착: 63 → 94.4

**초기 실패**

- 사망자가 없는 부상자 1명 사고를 사망 사고로 환각함
- 안전검사ㆍ자율안전확인 질문을 특별교육 질문으로 오분류함
- 종합보고서에서 직영 작업을 도급 작업으로 잘못 언급함

**개선**

- 사망자와 장기치료 부상자 인원 카운트 검증 추가
- `machine_inspection` 의도를 특별교육 경로와 분리
- ScenarioProfile의 직영ㆍ도급 구조를 모든 답변 경로에서 공유

**결과**

- 부상자 1명은 중대재해처벌법 제2조제2호나목의 2명 요건에
  미달한다는 결론을 정확히 출력함
- 제조ㆍ수입자의 자율안전확인 의무와 사용 사업주의 의무를 구분함

원본: [`test/test_caught_machine_result.md`](../test/test_caught_machine_result.md)

### 4. 조적 낙하물: 38 → 99.6

**초기 실패**

- 조적 작업을 굴착 특별교육 대상으로 억지 매핑함
- 낙하물 질문에 비계 설치와 안전대 조항이 출력됨
- 원청 책임과 종합보고서에 과거 비계 사고의 회사명이 그대로 나타남

**개선**

- 파이프라인 앞단에 `ScenarioProfileNode`를 추가
- 회사, 작업, 사고 유형, 도급 구조와 사상자 수를 한 번 구조화해 모든 경로에서 공유
- 조적 특별교육 비대상 판단과 낙하물 방지 의도를 별도로 추가
- 제13조ㆍ제14조ㆍ제20조의 낙하물ㆍ발끝막이판ㆍ출입통제 근거 연결

**결과**

- 적용 가능한 특별교육 조항이 없을 때 다른 작업 조항을 만들지 않고
  `대상 아님`으로 판단함
- 경로마다 남아 있던 과거 시나리오 고정값이 제거됨

원본: [`test/test_struck_falling_result.md`](../test/test_struck_falling_result.md)

## 공통 구조 개선

### ScenarioProfileNode

LLM이 법률 판단을 하기 전에 사고 사실만 구조화한다. 이후 원문 기반
결정형 검증으로 회사명, 사고 유형, 작업, 사망ㆍ부상 인원과 도급 구조를
교정한다. 시나리오 hash가 달라지면 과거 분석은 무효화한다.

### QuestionScopeNode와 의도 분류

일반 법령 설명과 저장된 사고 판단을 분리한다. 특별교육, 안전검사,
도급 책임, 경영책임자 처벌과 종합보고서를 서로 다른 의도로 분류한다.

### 결정형 법령 라우팅

사망ㆍ부상 기준, 작업별 특별교육, 법정형과 같이 답이 정형화된 영역은
LLM이 조항을 새로 선택하지 않는다. LLM은 검색 근거 안에서 사실관계와
설명을 보강하는 역할에 집중한다.

### Text RAG와 Table RAG

법령 본문과 별표ㆍ표를 서로 다른 ChromaDB에 저장한다. 특별교육 항목,
교육시간과 과태료처럼 표 구조가 중요한 정보는 행 단위로 검색한 뒤 본문
근거와 합친다.

### Citation Validator

답변에 적힌 법령명, 조항과 별표를 반환된 참고 근거와 대조한다. 검증되지
않은 조항이나 책임 판단에 필수적인 근거 누락을 `PASS`, `WARN`, `FAIL`로
기록한다.

## 응답시간 해석

응답시간은 경로에 따라 크게 다르다.

- `direct_candidate`: 검증된 법령 규칙을 코드가 조합하므로 수 ms에서 수 초
- `rag_llm`: Text/Table 검색 후 EXAONE이 생성하므로 수 초에서 수십 초

따라서 1~2ms 응답을 캐시 재사용으로 간주하지 않는다. 관리자 질문 그래프의
`execution=deterministic_legal_rule`과 `cache_used` 값을 함께 확인한다.

## 한계

- 수동 개선 평균은 결과 보고서가 정리된 4개 사고 유형만 집계했다.
- 비계 추락과 인양물 사고는 자동 배포 평가에는 포함되지만 동일한 형식의
  1차ㆍ재평가 수동 점수 보고서가 없어 개선 평균에서 제외했다.
- 리튬전지 다수사망 사고는 복합 holdout 성격으로 실제 API와 출처 검증을
  통과했지만 위 4개 수동 평가와 동일한 루브릭 점수로 합산하지 않았다.
- 감전, 질식과 화학물질 누출 등 미등록 사고는 별도 법령 검토와 평가셋
  확장이 필요하다.
- 이 결과는 법률 판단 보조 시스템의 고정 평가셋 결과이며 법률 자문이나
  실제 사건에 대한 정확도를 보증하지 않는다.
