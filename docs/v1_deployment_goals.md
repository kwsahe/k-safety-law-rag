# K-Safety Law RAG — 1차 배포(v1.0) 목표 및 합격 기준

> 대상: 하청(수급) 건설·제조 기업의 사고 발생 시 법령 위반 판단 시스템
> 목적: 1차 배포를 위한 필수 통과 기준 정의
> 원칙: 아래 "필수 통과" 항목이 100% 작동해야 배포 가능

---

## 배포 대상 사고 유형 선정 근거

하청 기업 산업재해는 특정 유형에 집중된다. 고용노동부 산업재해
통계상 건설·제조 하청 사고의 대다수가 아래 5개 유형에 해당한다.
1차 배포는 이 5개 유형을 완벽히 처리하는 것을 목표로 한다.

| 우선순위 | 사고 유형 | 하청 현장 발생 빈도 | 핵심 법령 |
|---------|---------|-----------------|---------|
| 1 | 추락 (비계·개구부·사다리) | 최다 | 별표5 제23호, 기준규칙 제42조 |
| 2 | 끼임·협착 (기계·설비) | 다발 | 기준규칙 제87조, 별표5 제1호 |
| 3 | 물체에 맞음 (낙하·비래) | 다발 | 기준규칙 제14조, 별표5 제14호 |
| 4 | 붕괴·무너짐 (굴착·토사) | 중대재해 비중 높음 | 별표5 제19호, 기준규칙 제338조 |
| 5 | 화재·폭발 (용접·유증기) | 사망 비중 높음 | 별표5 제12호, 기준규칙 제241조 |

## 1차 배포 목표 정의

### 배포 범위 (v1.0에서 지원)

```
지원함:
  ✅ 5개 사고 유형별 위반 조항 특정
  ✅ 산업안전보건법 / 중대재해처벌법 구분 판단
  ✅ 사망 / 부상(2명 이상) 처벌 수위 구분
  ✅ 원청·하청 도급 책임 판단
  ✅ 사업주 / 경영책임자 / 법인 책임 주체 구분
  ✅ page 7 (위반 사항) + page 12 (종합 평가) payload 출력

지원 안 함 (v2 이후):
  ❌ 책임 배분 비율 (판례·법원 영역)
  ❌ 재범 가중처벌 자동 판단
  ❌ 근로자 과실상계 계산
  ❌ 영상 자동 분석 (별도 모듈)
```

## 필수 통과 기준 (배포 게이트)

아래 항목은 **5개 사고 유형 전부에서 100% 통과**해야 배포 가능.
하나라도 실패 시 배포 보류.

### 게이트 1 — 위반 조항 정확도

```
[필수] 사고 유형별 핵심 조항을 정확히 특정한다.
  추락    → 별표5 제23호
  끼임    → 별표5 제1호
  물체맞음 → 별표5 제14호
  붕괴    → 별표5 제19호
  화재    → 별표5 제12호

합격 기준:
  ✅ 사고 유형과 무관한 조항 오발화 0건
  ✅ 이전 시나리오 조항 혼입 0건
  ✅ 교육 내용 타 항목 혼입 0건
```

### 게이트 2 — 사망/부상 처벌 분기

```
[필수] 사망과 부상(2명 이상)의 처벌 수위를 정확히 구분한다.

  사망 (제2조제2호가목):
    대표이사 제6조제1항 — 1년 이상 징역 또는 10억 이하 벌금
    법인 제7조제1호 — 50억 이하 벌금

  부상 2명 이상 (제2조제2호나목):
    대표이사 제6조제2항 — 7년 이하 징역 또는 1억 이하 벌금
    법인 제7조제2호 — 10억 이하 벌금

합격 기준:
  ✅ 사망 시나리오에서 부상 조항 출력 0건
  ✅ 부상 시나리오에서 사망 조항 출력 0건
  ✅ 법인 벌금 50억/10억 혼동 0건
```

### 게이트 3 — 시나리오 격리

```
[필수] 각 사고 시나리오의 회사명·작업종류·협력업체명이
       정확히 반영되고, 이전 시나리오 내용이 섞이지 않는다.

합격 기준:
  ✅ 회사명 오출력 0건 (예: 화재 사고에 "스파일럿건설" 금지)
  ✅ 작업 종류 오출력 0건 (예: 굴착 사고에 "비계 작업" 금지)
  ✅ 협력업체명 오출력 0건 (D사 질문에 B사 답변 금지)
  ✅ 캐시 키에 시나리오 식별자 포함
```

### 게이트 4 — 법령 구분

```
[필수] 산업안전보건법과 중대재해처벌법을 혼동하지 않는다.

합격 기준:
  ✅ 산안법 과태료(50만원대) ≠ 중재법 과태료(1천만원대)
  ✅ 사업주(현장) ≠ 경영책임자(CEO) 책임 주체 구분
  ✅ 근로자 처벌 주체 아님 명시
```

### 게이트 5 — 출력 안정성

```
[필수] payload 형식이 안정적으로 출력된다.

합격 기준:
  ✅ 청크 원문 그대로 출력 0건
  ✅ 응답시간 60초 이내 (page 7 + page 12 합산)
  ✅ 출처 검증 PASS (WARN 허용, FAIL 불가)
  ✅ 캐싱 오류로 인한 이전 답변 재출력 0건
```

## 사고 유형별 테스트 점수 목표

각 사고 유형마다 5문항(Q1~Q5) 테스트. 채점 기준은 문항별 100점.

| 사고 유형 | Q1 위반조항 | Q2 복수조항 | Q3 중재법 | Q4 도급 | Q5 종합 | 목표 평균 |
|---------|-----------|-----------|---------|--------|--------|---------|
| 추락 (비계) | 90+ | 90+ | 90+ | 90+ | 90+ | **90점** |
| 끼임 (기계) | 90+ | 90+ | 90+ | 90+ | 90+ | **90점** |
| 물체맞음 (낙하) | 90+ | 90+ | 90+ | 90+ | 90+ | **90점** |
| 붕괴 (굴착) | 90+ | 90+ | 90+ | 90+ | 90+ | **90점** |
| 화재 (용접) | 90+ | 90+ | 90+ | 90+ | 90+ | **90점** |

**배포 조건: 5개 유형 전부 평균 90점 이상 + 필수 게이트 5개 전부 통과**

## 배포 차단 이슈 (해결 완료)

### 해결 1 — 사망/부상 처벌 분기

```
결과: 사망은 제2조제2호가목·제6조제1항·제7조제1호,
      6개월 이상 치료 부상자 2명은 제2조제2호나목·
      제6조제2항·제7조제2호로 분리됨.
```

### 해결 2 — 시나리오 격리

```
결과: 질문과 시나리오를 결합한 캐시 키를 사용하고 회사명·수급업체명을
      현재 시나리오에서 추출함. 미등록 (주)새빛물류/G사 시나리오 통과.
```

### 해결 3 — 굴착·흙막이 조항 검색

```
결과: 현행 기준규칙 제338조·제339조·제340조·제347조와
      산업안전보건법 제51조를 검색·검증 근거로 연결함.
```
