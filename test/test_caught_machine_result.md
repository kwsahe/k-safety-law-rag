## 응답시간 관련 정정 사항

초기 채점에서 Q2(1ms)·Q4(2ms)를 캐시 재사용으로 오판했으나, 실제로는 direct_candidate 결정형(deterministic) 경로임을 확인.

```
direct_candidate 경로:
  질문 의도 분류 → 코드가 법령 규칙을 즉시 조합 → LLM 미호출 → 1~2ms
  답변 캐시 로직 없음. 관리자 CLI에 경로 명시됨.
```

Q2와 Q4의 답변이 동일한 이유는 두 질문이 동일 의도(machine_inspection)로 분류되어 같은 법령 규칙 세트를 조합하기 때문. 캐시 재사용이 아닌 "같은 의도 → 같은 결정형 출력"으로, 환각 없는 일관성이 오히려 강점.

| Q1 | rag_llm | 17.8초 | 정상 (LLM 생성) |
| Q2 | direct_candidate | 1ms | 정상 (결정형) |
| Q3 | direct_candidate | 3.3초 | 정상 |
| Q4 | direct_candidate | 2ms | 정상 (결정형) |
