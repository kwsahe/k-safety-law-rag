# 최종 종합 테스트셋 — 실제 사고 기반 (리튬전지 화재·폭발)

> 참고 사고: 아리셀 리튬 1차전지 공장 화재·폭발 (2024.6.24, 화성)
>           노동자 23명 사망 / 다수 이주노동자 / 파견·도급 구조
> 판결: 1심 대표 징역 15년·법인 벌금 8억(2025.9) → 2심 대표 징역 4년(2026.4)
> 목적: 5개 사고 유형(추락·화재·붕괴·끼임·물체맞음) 검증을 마친 뒤
>       실제 판례의 복합 쟁점으로 시스템 종합 능력 최종 검증
> 난이도: 최상 (다수 사망 + 파견/도급 + 이주노동자 + 반복 사고 전조)

---

## 설계 배경

이 테스트셋은 실제 아리셀 판결에서 법원이 인정한 6개 핵심 주의의무
위반을 기반으로 구성한다. 앞선 5개 사고 유형과 달리 다음 복합 쟁점을
동시에 담는다.

```
① 다수 사망 (23명) — 단일 사망과 다른 양형 가중
② 파견·도급 혼재 구조 — 원청/파견/도급 책임 교차
③ 이주노동자 위험공정 배치 — 구조적 가중인자
④ 반복 사고 전조 무시 — 5차례 화재 이력
⑤ 위험성평가 서류 조작 — 형식적 이행의 실질 위반
⑥ 비상구 설치 의무 — 1심/2심 판단이 갈린 쟁점
```

실제 판례이므로 정답에 "법원 판단이 갈린 지점"을 포함하여,
시스템이 확정적으로 단정하지 않고 쟁점을 제시하는지도 검증한다.

```

- 현장: 리튬 1차전지(비충전식) 제조 공장 3동 2층
- 사업장: (주)한빛에너지셀 / 상시 근로자 55명 / 매출액 120억원
- 사고 일시: 2024년 O월 O일, 오전 10시 30분경
- 사고 위치: 공장 3동 2층 전지 완제품 검사·포장 구역
             (원통형 리튬전지 약 3만 5천 개 적재)
- 사고 결과: 전지 1개 셀에서 발열·폭발이 연쇄적으로 확산되어
             화재·폭발 발생, 근로자 23명 사망, 8명 부상

[사고 경위]
전지 완제품 검사 작업 중 원통형 리튬전지 1개에서 발열이 시작되어
급격히 폭발하였고, 인근 적재 전지 3만 5천 개로 연쇄 폭발이 확산됨.
화재는 순식간에 2층 전체로 번졌고, 유독가스와 화염으로
작업 중이던 근로자들이 대피하지 못하고 다수 사망함.
사망자 다수는 인력공급업체를 통해 투입된 이주노동자였음.
사고 전 약 5차례에 걸쳐 유사한 전지 발열·화재가 있었으나
작업을 중단하지 않고 계속 진행하였고, 발열 전지에 대한
분리보관·발열검사 조치가 이루어지지 않았음.
위험성평가는 서류상으로만 존재하고 실제 위험요인(리튬전지
폭발·유독가스)이 반영되지 않은 형식적 문서였음.
2층 작업 공간에서 비상구·비상통로 확보가 미흡하여
대피 경로가 제한되었음.

[사업장 및 근로자 현황]
- 사망자: 23명 (다수 인력공급업체 소속 이주노동자)
- 부상자: 8명
- 고용 형태: 직영 + 인력공급업체(파견/도급 혼재) 투입
- 안전보건교육: 채용 시·작업내용 변경 시 교육 미실시
                (특히 이주노동자 대상 안전교육 부재)
- 위험성평가: 서류상 존재하나 리튬전지 폭발 위험 미반영 (형식적)
- 발열 전지 조치: 발열검사·분리보관 절차 미운영
- 반복 사고 이력: 사고 전 5차례 유사 발열·화재 발생, 작업 지속
- 소방·대피: 소방훈련 미실시, 비상구·비상통로 확보 미흡
- 유해물질: 리튬(물반응성·발화성 물질) 대량 취급
- 안전보건관리체계: 형식적 마련, 반복 사고 전조 무시
- 경영책임자: 대표이사가 자금·인사·수주·주요 경영 판단 관여
              (명목상 대표 아님)
- 계약 구조: 인력공급업체와 도급/파견 계약,
             불법파견·위장도급 의심 정황
```

## Q1. 위험물질 취급·안전교육 위반 판단

**프롬프트:**
```
위 사고에서 리튬전지(위험물질) 취급 및 안전보건교육 관련
사업주 의무 위반이 법령 위반에 해당하는가?
위반 조항과 함께 판단하라.
```

**정답:**
```
위반 여부: YES

[위험물질 취급]
① 물반응성·인화성 물질 취급 안전조치
   - 근거: 산업안전보건기준에 관한 규칙 제225조~제232조
     (위험물 제조·취급 시 폭발·화재 예방조치)
   - 판단: 리튬은 물반응성·발화성 물질, 대량 취급 시
           발열·폭발 방지 조치 및 분리보관 의무
           → 발열 전지 분리보관·검사 미실시 → 위반

② 발열·화재 발생 시 작업중지
   - 근거: 산업안전보건법 제51조 (급박한 위험 시 작업중지)
   - 판단: 5차례 발열·화재 전조에도 작업 지속 → 위반

[안전보건교육]
③ 채용 시·작업내용 변경 시 교육 미실시
   - 근거: 산업안전보건법 제29조제1항·제2항
   - 판단: 이주노동자 포함 근로자 안전교육 미실시
           특히 위험물질 취급 교육 부재 → 위반

[비상구 설치 — 쟁점]
④ 비상구·비상통로 확보
   - 근거: 산업안전보건기준에 관한 규칙 제17조
   - 판단: 위험물질 취급 작업장 비상구 설치 의무
   - ※ 쟁점: 리튬전지 적재 공간이 "위험물질 취급 작업장"인지
            "작업장이 있는 건축물의 한 층"인지에 따라
            각 층 비상구 설치 의무 해석이 갈릴 수 있음
            (법원 1심·2심 판단 상이)

근거: 산업안전보건법 제29조·제51조,
     기준규칙 제17조·제225~232조
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 위험물질(리튬) 취급 안전조치 위반 | 25점 |
| 발열 전조 무시 작업중지 미실시 (제51조) | 20점 |
| 안전보건교육 미실시 (제29조) | 20점 |
| 비상구 조항 언급 (제17조) | 20점 |
| 비상구 의무 해석 쟁점 존재 인식 | 15점 |

**실패 패턴:**
- 굴착·비계 등 이전 사고 조항 혼입
- 리튬을 일반 화재로만 처리 (물반응성 물질 특성 누락)
- 비상구 쟁점을 확정적으로 단정 (1심/2심 갈린 사안)

## Q2. 다수 사망 중대산업재해 + 처벌 수위

**프롬프트:**
```
위 사고에서 중대재해처벌법이 적용되는가?
23명 사망이라는 다수 사망이 처벌 수위에 미치는 영향과
경영책임자 처벌 수위를 판단하라.
```

**정답:**
```
[중대재해처벌법 적용]
적용됨.
- 제2조제2호가목: 사망자 1명 이상 → 23명 사망으로 명백히 충족
- 제3조: 상시 근로자 55명 → 5명 이상 → 적용

[경영책임자 처벌 수위]
- 제6조제1항: 1년 이상의 징역 또는 10억원 이하의 벌금
  (사망 사건 법정형)
- 대표이사가 명목상이 아닌 실질 경영책임자
  (자금·인사·수주·경영 판단 관여) → 경영책임자 해당

[다수 사망의 양형 영향]
- 제6조제1항의 법정형 하한 1년은 "최경량 유형" 기준
- 23명 다수 사망은 최경량 유형에서 현저히 이탈
  → 하한에서의 이탈 폭이 커야 함 (가중)
- 실제 판례: 1심 징역 15년 (다수 사망·의무위반 정도 반영)

[구조적 가중인자]
- 이주노동자 위험공정 집중 배치
- 불법파견·위장도급 의심 구조
- 반복 사고 전조(5차례) 무시
- 위험성평가 서류 조작(형식적 이행)
→ 위험을 취약 노동자에게 전가한 구조로 강한 비난가능성

[법인 처벌]
- 제7조제1호: 50억원 이하의 벌금
- 실제 판례: 법인 벌금 8억원

[민사]
- 제15조: 손해액의 5배 이내 징벌적 배상

근거: 중대재해처벌법 제2조제2호가목, 제3조,
     제6조제1항, 제7조제1호, 제15조
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 제2조제2호가목 (사망) + 제3조 적용 | 20점 |

**실패 패턴:**

## Q3. 파견·도급 혼재 구조의 책임 판단

**프롬프트:**
```
사망자 다수가 인력공급업체를 통해 투입된 이주노동자인 상황에서
원청 (주)한빛에너지셀의 책임이 성립하는가?
파견·도급 관계에서의 책임 구조를 산업안전보건법과
중대재해처벌법 각각의 관점에서 판단하라.
```

**정답:**
```
[산업안전보건법 관점]
- 제63조: 도급인의 안전조치·보건조치 의무
  (관계수급인 근로자에 대한 안전보건조치)
- 제64조: 도급 시 산업재해 예방조치
- 파견근로자: 파견법 + 산업안전보건법상
  사용사업주가 안전보건조치 의무 부담
- 위장도급·불법파견인 경우 실질 사용자인 원청이
  직접 사용자 책임 부담

[중대재해처벌법 관점]
- 제4조: 자신의 종사자에 대한 안전보건 확보의무
  ("종사자"에는 도급·용역·위탁의 각 단계 종사자 포함)
- 제5조: 도급·용역·위탁 시 실질적 지배·운영·관리하는
  경우 안전보건 확보의무
- 원청이 공장·설비·작업을 실질적으로 지배·관리
  → 인력공급업체 소속 이주노동자도 원청 경영책임자의
    안전보건 확보의무 대상

[핵심 — 위험의 외주화]
- 위험공정에 파견·이주노동자를 집중 배치한 구조
- 형식적 도급/파견 계약으로 책임을 회피할 수 없음
- 실질적 지배·운영·관리가 인정되면
  원청 경영책임자가 중대재해처벌법 책임 주체

[수급인 관리 의무]
- 시행령 제4조제9호: 인력공급업체(수급인)의 안전보건
  역량 평가 및 관리 의무
  → 이주노동자 안전교육 관리 부재 → 위반

근거: 산업안전보건법 제63조·제64조,
     중대재해처벌법 제4조·제5조, 시행령 제4조제9호
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 산안법 제63조·제64조 도급인 책임 | 20점 |
| 파견/위장도급 시 실질 사용자 책임 | 20점 |
| 중재법 제4조 "종사자" 범위 (도급 단계 포함) | 20점 |
| 제5조 실질적 지배 → 원청 책임 | 20점 |
| 위험의 외주화 구조 비판적 인식 | 20점 |

**실패 패턴:**
- "인력공급업체 소속이라 원청 무관" 오판
- 파견과 도급을 구분 없이 처리
- 위장도급 쟁점 누락

## Q4. 형식적 위험성평가·반복 전조의 판단

**프롬프트:**
```
위험성평가가 서류상으로만 존재하고 실제 위험이 반영되지 않은 점,
사고 전 5차례 발열·화재 전조가 있었음에도 작업을 지속한 점이
법적으로 어떻게 평가되는가?
경영책임자 의무 이행의 관점에서 판단하라.
```

**정답:**
```
[형식적 위험성평가 — 실질 위반]
- 시행령 제4조제3호: 유해·위험요인 확인·개선 절차 마련 및
  반기 1회 이상 점검 의무
- 시행령 제4조제3호 단서: 위험성평가 실시 의무
- 판단: 서류상 위험성평가는 "실시"로 인정되지 않음
  → 리튬전지 폭발·유독가스라는 핵심 위험이 미반영된
    형식적 문서는 실질적 의무 이행으로 볼 수 없음
  → 서류 조작은 오히려 의무 위반의 고의성 방증

[반복 사고 전조 무시]
- 5차례 발열·화재 전조 = 위험요인이 명백히 현실화된 상황
- 시행령 제4조제3호에 따른 개선 조치 의무 발생
- 발열 전지 분리보관·검사 절차 미운영 → 개선 방치
- 산업안전보건법 제51조 작업중지 의무도 발생
  (급박한 위험 인식 가능한 상황)

[경영책임자 의무 이행 판단]
- 안전보건관리체계를 "구축"만 하고 "이행"하지 않음
- 반복 전조를 보고받고도 개선하지 않았다면
  경영책임자의 안전보건 확보의무 위반 명백
- 실제 판례: "폭발사고 전조증상 무시, 안전관리시스템
  구축의무 방치"로 인과관계 인정

[예견가능성]
- 5차례 전조 + 직전 화재와 동일 전지
  → 사고 예견가능성 인정
  → "과도한 주의의무 요구"가 아님

근거: 중대재해처벌법 제4조, 시행령 제4조제3호,
     산업안전보건법 제51조
```
