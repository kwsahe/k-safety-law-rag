# RAG 테스트셋 — 용접 작업 중 화재·폭발 사망사고

> 사고 유형: 화재·폭발 (용접 작업 중)
> 사업장 규모: 상시 근로자 30명 (두 법령 모두 적용)
> 난이도 구성: 1단계(위반 조항) · 2단계(책임 주체) · 3단계(종합 평가) 균형

```
[사고 개요]
- 현장: 제조업 공장 내 철골 구조물 보수 작업 현장
- 사업장: (주)한국제조기술 / 상시 근로자 30명 / 매출액 50억원
- 사고 일시: 2024년 3월 15일, 오후 2시 30분경
- 사고 위치: 공장 2층 철골 구조물 보수 구역
- 사고 결과: 용접 작업 중 인근 도료 용제 증기에 불꽃이 점화되어
             화재·폭발 발생, 용접 작업자 P씨 사망

[사고 경위]
공장 2층 철골 구조물 보수를 위해 용접 작업자 P씨가 산소-아세틸렌
용접 작업을 수행하고 있었음.
동일 공간 인근에서 도장 작업자 Q씨가 유기용제계 도료(신나 포함)를
사용한 도장 작업을 병행하고 있었음.
도장 작업 중 발생한 용제 증기가 충분히 환기되지 않은 상태에서
용접 불꽃이 점화원이 되어 화재·폭발이 발생함.
P씨는 전신 화상으로 즉시 사망하였고, Q씨는 경상을 입어 병원 후송됨.
사고 당시 해당 구역에는 화기 사용 금지 표지가 없었고,
불활성 가스 등 폭발 방지를 위한 환기 조치도 미실시됨.
용접 작업 전 화재·폭발 위험성에 대한 작업 허가(화기작업 허가서)도
발급되지 않았음.

[사업장 및 근로자 현황]
- 재해자: P씨 / 남성 / 용접 작업자 / 고용기간 6개월 / 사망
- 부상자: Q씨 / 도장 작업자 / 경상
- 특별안전교육: P씨·Q씨 모두 화재·폭발 위험 작업 관련 미실시
- 작업 전 위험성평가: 미실시
- 화기작업 허가: 미발급 (사업장 내 화기작업 허가 절차 미운영)
- 환기 조치: 미실시 (유기용제 증기 농도 측정 없이 작업 진행)
- 안전보건관리체계: 형식적으로 마련되어 있으나
                   동시 작업 위험성 점검 및 화기작업 관리 미흡
- 보호구: P씨 용접용 보호면 미착용 / Q씨 방독마스크 미착용
- 도급 관계: 도장 작업을 외부 업체 C사에 도급
             원청(한국제조기술)의 도급 작업 안전보건 확보의무 검토 필요
- 현장 관리: 용접과 도장 동시 작업에 대한 작업지휘자 미배치
```
