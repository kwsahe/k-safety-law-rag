# RAG 테스트셋 — 물체에 맞음 (낙하·비래) 사고

> 사고 유형: 물체에 맞음 (고소 작업 중 자재 낙하)
> 사업장 규모: 상시 근로자 22명 (두 법령 모두 적용)
> 핵심 검증: 낙하물 방지 조항 (기준규칙 제14조·제15조) + 사망 사고
> 난이도 구성: 1단계(위반 조항) · 2단계(책임 주체) · 3단계(종합 평가) 균형

## 공통 시나리오

```
[사고 개요]
- 현장: 오피스텔 신축 건설현장 (지상 12층)
- 사업장: (주)신성종합건설 / 상시 근로자 22명 / 공사금액 80억원
- 사고 일시: 2024년 9월 5일, 오전 9시 40분경
- 사고 위치: 지상 8층 외부 비계 하부 통로
- 사고 결과: 8층에서 낙하한 벽돌 더미에 하부 통로를 지나던
             근로자 U씨가 머리를 맞아 사망

[사고 경위]
지상 8층 외부 비계에서 조적공 V씨가 벽돌 운반 작업을 하던 중,
비계 작업발판 가장자리에 임시로 쌓아둔 벽돌 더미가
발에 걸려 하부로 떨어짐.
때마침 8층 하부 통로를 지나던 근로자 U씨의 머리 위로
벽돌이 낙하하여 U씨가 사망함.
사고 당시 비계 외부에는 낙하물 방지망이 설치되지 않았고,
작업 구간 하부에는 출입금지 구역 설정이나
방호선반(낙하물 방지 선반)도 없었음.
비계 작업발판에는 발끝막이판(폭목)이 설치되지 않아
자재가 쉽게 굴러떨어질 수 있는 상태였음.
U씨는 안전모를 착용하고 있었으나 낙하 충격을 견디지 못함.

[사업장 및 근로자 현황]
- 재해자: U씨 / 남성 / 신호 및 운반 보조 / 고용기간 3개월 / 사망
- 낙하 유발자: V씨 / 조적공 / 벽돌 임시 적재
- 사망자: 1명
- 특별안전교육: V씨 조적(벽돌) 작업 관련 미실시
- 작업 전 위험성평가: 미실시
- 낙하물 방지망: 미설치
- 방호선반 / 발끝막이판: 미설치
- 출입금지 구역: 하부 통로 미통제
- 안전보건관리체계: 형식적으로 마련되어 있으나
                   상하 동시 작업 위험 점검 및 낙하물 방지 조치 미흡
- 보호구: U씨 안전모 착용 (낙하 충격 초과)
- 도급 관계: 조적 작업을 전문업체 E사에 도급
             원청의 도급 작업 안전보건 확보의무 검토 필요
- 작업지휘자: 미배치 (상하 동시 작업 통제 필요)
```

## Q1. 난이도: 하 — 조적/운반 작업 특별안전교육 위반

**프롬프트:**
```
위 사고에서 작업 관련 특별안전교육 미실시가
법령 위반에 해당하는가?
위반 조항과 교육 내용을 함께 제시하라.
```

**정답:**
```
위반 여부: YES

[위반 조항]
산업안전보건법 시행규칙 별표 5
- 조적/벽돌 운반 작업 자체는 특별교육 대상이 아닐 수 있으나,
  이 사고의 핵심은 낙하물 위험 작업 및 고소 작업 관리 문제
- 관련 특별교육: 별표 5 중 해당 작업 유형 검토 필요
  (건물 등의 해체작업, 흙막이 지보공 등과 달리
   단순 조적은 특별교육 명시 대상 아님)

[핵심 판단]
이 사고는 특별교육 미실시보다
낙하물 방지 조치 미흡(기준규칙 제14조)이 핵심 위반.
특별교육 관련해서는 별표 5에 조적 작업이
명시되어 있지 않으므로, 일반 안전보건교육
(산업안전보건법 제29조제1항·제2항) 미실시로 판단.

[일반 안전보건교육 미실시]
- 근거: 산업안전보건법 제29조
- 신규 채용 시 교육, 작업내용 변경 시 교육 미실시

근거: 산업안전보건법 제29조, 시행규칙 별표 4·5 검토
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 조적 작업이 특별교육 명시 대상 아님을 판단 | 35점 |
| 무리하게 특별교육 조항 억지 매핑하지 않음 | 30점 |
| 일반 안전보건교육(제29조) 또는 낙하물 조치로 전환 | 35점 |

**실패 패턴:**
- 조적 작업에 굴착(제19호)·비계(제23호) 특별교육 억지 매핑
- 존재하지 않는 "조적 특별교육" 조항 환각
- 이전 시나리오 조항 혼입

> **설계 의도:** 모든 사고가 특별교육 대상은 아님.
> 시스템이 "특별교육 대상 아님"을 정직하게 판단하는지,
> 억지로 조항을 만들어내지 않는지 검증하는 함정 문항.

## Q2. 난이도: 중 — 낙하물 방지 조치 위반 (핵심)

**프롬프트:**
```
위 사고에서 확인된 낙하물 방지망 미설치,
발끝막이판 미설치, 하부 출입통제 미실시가
법령 위반에 해당하는가?
각 항목별로 위반 조항과 함께 판단하라.
```

**정답:**
```
[위반 사항 3가지]

① 낙하물 방지망·방호선반 미설치
   - 근거: 산업안전보건기준에 관한 규칙 제14조
   - 판단: 높이 3미터 이상 장소에서 물체 낙하 위험 시
           낙하물 방지망, 방호선반 설치 또는
           출입금지구역 설정 등 조치 의무
           → 미설치 위반

② 발끝막이판(폭목) 미설치
   - 근거: 산업안전보건기준에 관한 규칙 제13조
   - 판단: 작업발판 끝·개구부에서 물체가 떨어지지 않도록
           발끝막이판 설치 의무 (안전난간 구성 요소)
           → 미설치로 벽돌 굴러떨어짐 → 위반

③ 하부 출입통제 미실시
   - 근거: 산업안전보건기준에 관한 규칙 제20조
   - 판단: 낙하물 위험 구간 하부에 근로자 출입 금지
           또는 통제 의무
           → 상하 동시 작업 중 하부 통행 방치 → 위반
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 낙하물 방지망 + 제14조 | 35점 |
| 발끝막이판 + 제13조 | 30점 |
| 하부 출입통제 + 제20조 | 35점 |

**실패 패턴:**
- 특별교육(Q1)만 반복
- 제14조 낙하물 방지 조항 미검색
- 제13조·제20조 미인용

## Q3. 난이도: 상 — 중대재해처벌법 적용 + 처벌 수위 (사망)

**프롬프트:**
```
위 사고에서 중대재해처벌법이 적용되는가?
(주)신성종합건설 대표이사의 의무 위반 여부와
처벌 수위를 판단하라.
```

**정답:**
```
[중대재해처벌법 적용 여부]
적용됨.
- 제2조제2호가목: U씨 사망 → 중대산업재해 성립
- 제3조: 상시 근로자 22명 → 5명 이상 → 적용 제외 아님

[대표이사 의무 위반]
위반: YES

① 시행령 제4조제3호
   상하 동시 작업의 낙하물 위험요인 확인·개선
   절차 마련 및 반기 점검 의무
   → 낙하물 방지 조치 점검 절차 미작동

② 시행령 제4조제3호 단서
   작업 전 위험성평가 미실시
   → 상하 동시 작업 낙하 위험 사전 미확인

③ 시행령 제5조제3호
   관계 법령상 안전조치 이행 점검·보고 의무
   → 낙하물 방지망·출입통제 미실시 미인지·미시정

[처벌 수위 — 사망]

대표이사 개인:
- 1년 이상의 징역 또는 10억원 이하의 벌금
- 근거: 중대재해처벌법 제6조제1항 (사망)

법인:
- 50억원 이하의 벌금
- 근거: 중대재해처벌법 제7조제1호

민사:
- 손해액의 5배 이내 징벌적 배상
- 근거: 중대재해처벌법 제15조
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 제2조제2호가목 (사망) + 제3조 적용 확인 | 25점 |
| 시행령 제4조제3호 + 제5조제3호 위반 | 25점 |
| 대표이사 1년 이상·10억 (제6조제1항) | 20점 |
| 법인 50억 (제7조제1호) | 15점 |
| 민사 5배 (제15조) | 15점 |

**실패 패턴:**
- 사망인데 부상(제6조제2항·1억) 적용 → 붕괴/끼임 사고 로직 잔존
- 법인 10억(부상 기준) 출력 → 50억이어야 함
- 시나리오 맥락(낙하·신성종합건설) 미반영

> **설계 의도:** 직전 끼임 사고(부상 1명 → 미적용),
> 붕괴 사고(부상 2명 → 제6조제2항)를 거친 뒤
> 이번 사망 사고에서 제6조제1항(사망·50억)으로
> 정확히 복귀하는지 검증. 부상 로직이 잔존하면 실패.

## Q4. 난이도: 최상 — 도급 책임 비교

**프롬프트:**
```
조적 작업을 전문업체 E사에 도급한 상황에서
원청 (주)신성종합건설의 책임이 성립하는가?
산업안전보건법과 중대재해처벌법 각각의 근거를 제시하고
두 법령의 책임 범위 차이를 설명하라.
```

**정답:**
```
[산업안전보건법 — 행위 기반 책임]
- 제64조: 도급인은 관계수급인 근로자가 자신의
  사업장에서 작업하는 경우 산업재해 예방조치 이행 의무
- 이 현장: 원청 건설현장 내부 → 도급인의 장소 지배 인정
- 상하 동시 작업 조정, 낙하물 방지망 설치, 하부 출입통제 등
  구체적 안전조치 이행 의무 위반

[중대재해처벌법 — 체계 기반 책임]
- 제5조: 시설·장비·장소를 실질적으로 지배·운영·관리하면
  경영책임자의 안전보건 확보의무 부담
- 이 현장: 원청 건설현장 → 실질적 지배 인정
- 시행령 제4조제9호: 수급인(E사) 안전보건 역량
  평가기준·절차 마련 및 반기 점검 의무
  E사 안전관리 수준 평가 이력 없음 → 의무 위반

[두 법령 책임 범위 차이]
산업안전보건법:
  현장 단위 구체적 안전조치 행위 의무
  (낙하물 방지망·발끝막이판·출입통제·작업 조정)

중대재해처벌법:
  수급인 선정·관리 시스템 구축 의무
  (E사 선정 시 안전역량 평가해야 함)

근거: 산업안전보건법 제64조
      중대재해처벌법 제5조, 시행령 제4조제9호
```

**평가 기준:**
| 항목 | 배점 |
|------|------|
| 산안법 제64조 도급인 책임 | 25점 |
| 중재법 제5조 실질적 지배 조건 | 25점 |
| 시행령 제4조제9호 수급인 역량 평가 | 25점 |
| 행위 기반 vs 체계 기반 차이 구분 | 25점 |

## Q5. 난이도: 최상+ — 사고 상황 종합 평가

**프롬프트:**
```
위 사고 상황을 종합 평가하라.
다음 항목을 모두 포함하여 최종 보고서 형식으로 작성하라.

① 사고 원인 분석 (직접 원인 / 간접 원인)
② 법령 위반 사항 요약 (산업안전보건법 / 중대재해처벌법)
③ 책임 주체별 판단 (사업주 / 경영책임자 / 법인)
④ 즉시 취해야 할 재발방지 조치 (법적 근거 포함)
```

**정답:**
```
[사고 원인 분석]

직접 원인:
- 비계 작업발판 가장자리 벽돌 임시 적재
- 발끝막이판 미설치로 벽돌 굴러떨어짐
- 하부 통로 낙하물 방지망·출입통제 부재

간접 원인:
- 상하 동시 작업 위험성평가 미실시
- 낙하물 방지 조치 점검 절차 미작동
- 작업지휘자 미배치
- 경영책임자의 안전보건관리체계 이행 점검 미흡

[법령 위반 사항 요약]

산업안전보건법:
- 기준규칙 제14조: 낙하물 방지망·방호선반 미설치
- 기준규칙 제13조: 발끝막이판 미설치
- 기준규칙 제20조: 하부 출입통제 미실시
- 제29조: 안전보건교육 미실시
- 제64조: 도급 작업 안전보건 확보의무 미흡

중대재해처벌법:
- 제2조제2호가목: 중대산업재해 성립 (U씨 사망)

## 이전 테스트셋과의 차이점 + 핵심 함정

| 항목 | 끼임 사고 | 물체맞음 사고 |
|------|---------|-------------|
| 핵심 조항 | 별표5 제1호 (프레스) | 기준규칙 제14조 (낙하물) |
| 특별교육 | 프레스 = 대상 O | 조적 = 대상 X (함정) |
| 사고 결과 | 부상 1명 | 사망 1명 |
| 중재법 적용 | 미적용 (1명) | 적용 (사망 가목) |
| 처벌 조항 | 미적용 | 제6조제1항·제7조제1호 |
| 법인 처벌 | - | 50억 |

**Q1 함정 — 특별교육 대상 아님:**
```
이전 4개 사고: 굴착·비계·용접·프레스 = 모두 특별교육 대상
이번 조적 작업: 특별교육 명시 대상 아님

→ 시스템이 억지로 특별교육 조항을 만들지 않고
  "대상 아님"을 정직하게 판단하는지 검증
```

**Q3 함정 — 사망 조항 복귀:**
```
붕괴 사고: 부상 2명 → 제6조제2항 (7년·1억)
끼임 사고: 부상 1명 → 미적용
물체맞음: 사망 1명 → 제6조제1항 (1년 이상·10억), 법인 50억

→ 연속된 부상 사고 뒤 사망 사고에서
  제6조제1항으로 정확히 복귀하는지,
  부상 로직(제6조제2항·10억)이 잔존하지 않는지 검증
```
