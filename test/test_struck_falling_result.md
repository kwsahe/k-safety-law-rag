### Q1. 특별교육 위반 (조적=대상 아님 함정)

| 구분 | 1차 시도 | 재테스트 |
|------|---------|---------|
| 조항 | 별표5 제19호 (굴착) 환각 | "조적은 특별교육 대상 아님" 정확 판단 |
| 환각 | "굴착면 4m ≥ 2m" 없는 사실 생성 | 없음 |
| 억지 매핑 | 굴착 조항 억지 적용 | "제19·23·14호를 조적에 적용 금지" 명시적 거부 |
| 출처 검증 | WARN | PASS |
| 점수 | 20점 (F) | 100점 (S) |

**개선 핵심:**
- 신규 의도 `masonry_special_education_scope` 생성
- 조적 작업이 별표5 특별교육 명시 대상이 아님을 정직하게 판단
- 굴착·비계·크레인 조항을 조적에 대신 적용하면 안 된다고 명시적으로 거부
- 이 사고의 핵심 쟁점을 특별교육이 아닌 낙하물 방지(제14조)로 전환

```
1차 출력 (환각):

  → 낙하물 사고에 굴착 조항 + 없는 수치 환각

재테스트 출력 (정확):
  "단순 조적·벽돌 운반 작업은 별표5에 독립된 특별교육
   대상으로 명시되어 있지 않음. 굴착 제19호, 비계 제23호,
   크레인 제14호를 조적 작업에 대신 적용해서는 안 됩니다."
```

## 핵심 개선 — ScenarioProfileNode 도입

이번 개선의 핵심은 실행 파이프라인 맨 앞에 ScenarioProfileNode를
추가한 것이다.

```
1차 실행 노드:
  QuestionScopeNode → IntentClassifierNode → RetrievalPlanNode → CacheGuardNode

재테스트 실행 노드:
  ScenarioProfileNode → QuestionScopeNode → IntentClassifierNode
                       → RetrievalPlanNode → CacheGuardNode
  ^^^^^^^^^^^^^^^^^^ 신규 추가
```

**효과:**
1. 시나리오를 가장 먼저 프로파일링하여 회사명·사고유형·작업종류·
   협력업체명·사망여부·부상인원을 구조화된 프로파일로 추출
2. 이후 모든 경로(executive_liability, prime_contractor_liability,
   comprehensive_report 등)가 이 프로파일을 참조
3. 붕괴 사고 때 executive_liability만 부분 수정되어 나머지 경로에
   비계 사고가 고정되던 문제를 근본적으로 해결

**이전 방식의 한계:**
```
붕괴 사고 수정: executive_liability 경로에만 시나리오 주입 추가
  → Q3(executive_liability)는 통과
  → Q4(prime_contractor_liability), Q5(comprehensive_report)는
    비계 사고 하드코딩이 남아 우연히 통과하거나 실패

물체맞음 사고에서 이 한계가 드러남:
  → Q4·Q5가 스파일럿건설·B사·비계로 완전 고정
  → 경로별 개별 수정의 한계 확인
```

**ScenarioProfileNode 방식:**
```
파이프라인 진입 시점에 시나리오 1회 프로파일링
  → 모든 하위 경로가 동일 프로파일 공유
  → 경로별 개별 수정 불필요
  → 신규 사고 유형 추가 시에도 자동 적용
```

## 신규 의도(Intent) 추가

낙하물 사고 처리를 위해 2개의 신규 의도가 생성되었다.

| 의도 | 용도 | 대응 문항 |
|------|------|---------|
| masonry_special_education_scope | 조적=특별교육 대상 아님 판단 | Q1 |
| masonry_falling_controls | 낙하물 방지 조치 위반 판단 | Q2 |

이는 사고 유형별로 의도를 세분화하는 방식으로, 조적 작업의
특수성(특별교육 비대상)을 정확히 처리할 수 있게 되었다.

## 종합 의견

1차 시도에서 낙하물 사고에 비계·굴착 사고 내용이 대량 혼입되어
38점(F)이었으나, ScenarioProfileNode 도입 후 99.6점(S)으로
61.6점 개선되었다.

가장 의미 있는 성과는 두 가지다.

첫째, Q1의 특별교육 함정 통과. 지금까지 4개 사고(굴착·비계·용접·
프레스)가 모두 특별교육 대상이었던 것과 달리, 조적 작업은 특별교육
명시 대상이 아니다. 시스템이 억지로 조항을 만들지 않고 "대상 아님"을
정직하게 판단하며, 다른 작업 조항을 조적에 적용하면 안 된다고
명시적으로 거부한 것은 환각을 억제하는 판단 능력을 입증한다.

둘째, ScenarioProfileNode를 통한 시나리오 격리의 근본적 해결.
경로별 개별 수정의 한계를 파이프라인 앞단의 공통 프로파일링으로
해결하여, 향후 신규 사고 유형 추가 시에도 시나리오 격리가
자동으로 보장되는 구조를 확보했다.

이로써 5개 사고 유형(추락·화재·붕괴·끼임·물체맞음) 전부가
S등급에 도달하여 v1.0 배포 조건을 충족한다.
